# 三端界面设计资产

本目录保存 RAG Upper 用户端、企业端和平台管理端的界面设计基线、Image2 设计图以及动态交互说明。所有文档使用中文，设计图是前端实现和视觉回归的基准。

## 角色边界

- 用户端：面向企业普通员工，完成知识问答、企业搜索、证据核验、文档上传和人工追问处理。
- 企业端：面向租户管理员、知识运营人员和安全管理员，管理本企业知识、智能体、连接器、成员权限及质量评测。
- 管理端：面向平台运营与超级管理员，管理租户生命周期、平台审计、模型资源和基础设施。

## 交付顺序

1. 先完成全部页面设计图和动态说明。
2. 设计资产完整后再建立前端路由、壳层和组件。
3. 按用户端、企业端、管理端依次实现，并补齐真实后端接口。
4. 使用桌面端和移动端截图进行视觉回归，不以静态截图冒充可用页面。

## 目录约定

- `设计系统.md`：颜色、字体、网格、组件和图表规范。
- `页面矩阵.md`：13 个设计主页面、3 个共用页面及任务、证据、文档、入库任务、知识索引、智能体、评测、成员和审计详情页的角色、状态和接口范围。
- `动态规范.md`：静态设计图无法表达的交互和动效要求。
- `生成记录.md`：Image2 生成方式、风格锚点、资产清单和复刻注意事项。
- `实现验收.md`：34 类实际页面、46 条路由、真实接口、动态效果、验证结果和当前边界。
- `images/`：Image2 生成的页面设计图。

## 一比一复刻定义

前端实现必须匹配设计图的整体构图、色彩、间距、组件层级和信息密度。Image2 生成图中的中文可能存在字形错误，实际界面文字以 `页面矩阵.md` 和产品代码为准。页面必须具备真实交互、响应式布局、权限控制以及加载、空、错误和部分成功状态。
