# Image2 生成记录

## 生成方式

- 生成模式：Codex 内置 Image2 图像生成工具。
- 资产类型：高保真 `ui-mockup`。
- 桌面页面：15 张，生成尺寸约为 1487 x 1058。
- 移动适配：4 张，生成尺寸约为 853 x 1844。
- 风格锚点：先生成登录与租户选择页，后续页面通过已生成页面作为图像参考，保持品牌、网格、字体层级和语义色一致。
- 最终资产全部保存在项目内的 `docs/ui-design/images/`，不依赖 Codex 默认生成目录。

## 固定提示约束

每一张图都使用了以下共同约束，并根据页面任务补充具体功能：

- 工业印刷与信号系统风格，面向真实企业工作流。
- 雾白背景、中性碳黑结构、朱红主操作、硫黄绿成功、钴蓝证据和运行状态。
- 禁止紫蓝渐变、玻璃拟态、深蓝或蓝灰大面积背景、装饰性光球和 3D 插画。
- 页面圆角不超过 8px，避免卡片墙和卡片嵌套。
- 用户端强调任务、回答、证据和追问；企业端强调表格、批量操作、发布与回滚；管理端强调租户范围、审计证据和资源风险。
- 所有关键控件必须对齐，文字不能与相邻元素重叠。

## 前端复刻要求

- 设计图是构图、色彩、间距、组件层级和信息密度的视觉基准，不是要嵌入页面的整屏图片。
- Image2 生成的中文可能存在字形或日期错误，实际文字、数据字段和操作规则以 `页面矩阵.md`、接口契约和代码为准。
- 图中出现的每个主操作都必须有真实交互；未接入后端的能力显示明确不可用状态，不能用随机数或静态成功结果冒充。
- 桌面视觉回归基准使用 1440 x 1024；用户端移动回归基准使用 390 x 844。
- 动态效果按 `动态规范.md` 实现，并验证降低动态偏好。
