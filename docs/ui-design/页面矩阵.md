## 接口落实范围

### 已有接口可承接

- 身份与当前用户：`/api/auth/*`
- 流式问答：`/api/chat`
- 文档上传、断点续传、入库、删除：`/api/admin/documents*`、`/api/admin/uploads*`
- 审计事件：`/api/admin/audit-events`
- 后台任务：`/api/admin/jobs/{job_id}`
- 服务健康：`/api/health/*`
- 三端注意事项：由任务、文档、租户总览、审计事件和健康探针实时聚合
- 服务端会话历史与反馈：`/api/tasks`、`/api/tasks/{task_id}`、`/api/tasks/{task_id}/feedback`
- 检索与证据详情：`/api/search`、`/api/search/evidence/{evidence_id}`；证据按租户和用户隔离并设置 TTL
- 用户文档详情：`/api/documents/{document_id}`；重新执行 owner/ACL 授权并返回受限解析预览
- 文档原文件：`/api/documents/{document_id}/content`、`/api/admin/documents/{document_id}/content`；路径不出服务端，预览和下载分别审计
- 租户活动审计：`/api/admin/audit-events`；虽然沿用管理接口前缀，但按当前 JWT 租户强制过滤并要求 `audit:read`
- 文档任务：用户端 `/api/jobs*` 重新执行 owner/ACL，企业端 `/api/admin/jobs*` 强制租户隔离；提交入库响应返回 `job_ids`
- Worker 运行快照：`/api/platform/runtime/worker`；返回 Redis Stream、消费者组和当前租户任务事实，不将消费者注册冒充心跳
- 知识索引运行快照：`/api/enterprise/knowledge/runtime`；只查询当前 JWT 租户，联合返回文档期望切片、Milvus 实际切片、Neo4j 图谱规模及没有业务文档记录的孤立索引
- MCP 连接详情：`/api/enterprise/runtime/connections/{connection_id}`；仅探测发布目录中的服务端预配置端点，返回脱敏地址、状态、延迟和受影响智能体
- 模型运行详情：`/api/platform/models/detail?name=`；仅允许读取服务端配置或 Ollama 已安装模型，白名单返回模型元数据和当前进程状态
- 评测数据集详情：`/api/enterprise/evaluation/runs/{run_id}/dataset`；返回登记来源与文件完整性，不返回原始样本正文
- 检索运行分析：`/api/enterprise/search-analytics`；按当前 JWT 租户聚合审计窗口，只返回白名单运行字段，不返回查询原文、摘要或任意审计元数据

### 后续必须补充

- 独立审批型 HITL 的批准、拒绝、超时和升级处理；普通补充信息已支持从 LangGraph 断点恢复。
- PDF 页码/坐标级定位与高亮；原文件预览和下载已实现，当前证据已支持文档、版本和切片级定位。
- 租户、部门、成员、角色和资源 ACL 管理；当前成员详情只展示 JWT 与审计事实，不将已观测身份冒充目录成员。
- 智能体、路由规则、提示词版本、MCP 连接的在线编辑与发布历史；连接配置和即时探针详情已可读取。
- 在线评测数据集管理、运行调度与取消、反馈和成本统计；固定评测运行及数据集来源、划分和摘要已可读取。
- 平台租户配额、模型容量趋势、依赖服务历史状态和维护操作。
- 租户运行详情已覆盖当前令牌租户，但平台级租户目录、计费和跨租户配额控制面仍未接入。
- 服务探针详情已覆盖单次实时检查，但可用率、SLA、告警历史和故障持续时间仍需时序监控系统提供。
- 文档任务记录与详情已支持真实状态追踪；取消、人工重试和死信恢复仍需 Worker 控制命令与二次确认接口。
- Worker 队列页已支持实时快照和状态不一致提示；独立心跳、任务租约、历史趋势与告警仍需监控存储和 Worker 心跳协议。
- 知识索引运行页已支持当前租户的即时一致性核验；扫描超过 10,000 条索引记录时不提供文档级结论，长期趋势、自动修复和检索质量仍需独立监控与评测系统。
- MCP 连接详情已支持服务端配置核验和单次实时探针；可用率、告警历史、凭据轮换和连接变更仍需时序监控与受审计控制面。
- 模型详情已支持配置、安装、元数据和当前加载核验；QPS、请求队列、GPU 总量/利用率和容量趋势仍需 Exporter 与指标存储。
- 检索运行分析已支持审计窗口内成功率、P50/P95、零命中和失败类型；时间趋势、全量历史、SLO 与告警仍需指标存储。

最终实现不得以静态假数据替代这些主流程。尚未接通的能力必须明确显示为不可用状态，不能伪装成功。
