# 三端前端实现验收

## 实现范围

当前前端共实现 37 类实际页面、49 条可访问路由，覆盖公共登录、用户端、企业端和平台管理端。13 张桌面设计图中的“安全审计与系统运行”被拆成安全、运维、模型三个独立页面，并增加只读平台配置页；通知、帮助和个人资料按三端权限复用，共形成 9 条路由；任务、证据、文档、原文件、文档任务、知识索引、智能体、MCP 连接、模型、评测运行、评测数据集、成员、租户活动、审计事件、租户运行、服务探针和 Worker 队列详情页补齐列表后的核验流程。

## 已实现动态效果

- 用户问答按 SSE 内容块流式追加，提供停止、引用、附件和终态反馈。
- 用户工作台快捷任务分批进入，输入聚焦和拖拽附件具有状态反馈。
- 搜索加载、证据选择、任务刷新、文档上传与入库进度保持稳定布局。
- 检索结果可进入独立证据详情并在 TTL 内刷新恢复；文档详情支持 ACL 复核、解析预览和真实后端状态，并可在重新授权后预览或下载原文件。
- 历史会话可从任意浏览器直接恢复用户可见消息；LangGraph 检查点只负责执行状态，不向页面暴露系统或工具消息。
- 回答页支持真实复制、Markdown 导出、反馈提交和再次提问；引用未返回定位地址时“打开原文”保持明确禁用。
- 三端侧栏在移动端使用遮罩抽屉，关闭后不改变页面内容宽度。
- 企业端指标刷新、会话状态条、解析流水线和评测基线对比均由真实数据驱动。
- 智能体卡片可进入只读运行详情；MCP 连接可从编排页或智能体详情进入独立页面，区分配置、即时探针和历史监控能力；评测来源可进入运行详情并横向核对全部候选方案。
- 成员身份和审计事件可进入独立详情；移动端事件行提供明确的详情箭头，详情刷新重新执行服务端租户作用域查询。
- 企业管理员可按操作者、精确操作名和结果查询本租户活动，以游标加载更早事件，并从活动检查器进入同请求链详情。
- 用户和企业管理员可回看文档入库、清理任务；单次提交后以真实 `job_id` 进入详情，进行中任务自动轮询并在终态停止。
- 平台运维页可联合查看 Redis Stream、消费者组、死信和数据库活动任务，每 10 秒刷新并提示需要调查的状态不一致。
- 企业知识页可进入双路索引运行详情，将文档期望切片与 Milvus、Neo4j 实际值逐项核对，同时识别只有索引记录、没有业务文档记录的残留，并从有效文档记录返回详情。
- 管理端筛选审计事件时只更新结果区，并支持游标加载更早事件。
- 租户列表可进入独立运行详情，跨租户路径返回 404；服务列表可逐项执行实时探针并查看成功条件与超时。
- 模型清单可进入单模型运行详情，区分服务端配置、安装事实、元数据和当前加载状态；运行时离线时保留配置事实并标记待核验。
- 评测运行可进入数据集详情，核对公开来源、固定种子、样本分布、防泄漏控制及仓库产物/本地缓存的文件摘要。
- 顶部通知计数来自实时状态聚合，通知筛选与刷新不改变列表宽度；帮助页在就绪接口返回 503 时仍显示各依赖真实状态。
- 桌面侧栏可收起为图标导航；三端顶部搜索、租户、通知、帮助和个人资料入口均可到达实际页面。
- 全局支持 `prefers-reduced-motion: reduce`，降低动态偏好下取消位移和循环动画。

- 后端：在 Conda `rag` 环境运行 `python -m pytest -q`，当前 118 项通过；包含空库迁移、会话租户隔离、SSE 终态持久化、证据跨租户/跨用户隔离、文档 ACL、原文件目录边界与处置、任务提交 ID、用户任务 owner/ACL、企业任务租户隔离和筛选、Worker 队列/租户任务联合快照、知识索引租户隔离与后端降级、智能体和 MCP 发布清单、连接探针脱敏、模型运行时离线语义与详情字段脱敏、评测结果与数据集登记脱敏、跨平台文件摘要和路径边界、成员声明边界、审计筛选与追踪隔离、租户详情隔离、单服务探针、就绪状态聚合和依赖故障映射测试。
- Python 静态检查：运行 Ruff，平台与企业接口、测试和主应用无错误。
- 前端：运行 `npm run typecheck` 和 `npm run build`，TypeScript 与 Vite 生产构建通过。
- 数据库与容器：全新 SQLite 从 Alembic `0001` 升级到 `20260902_0003`，会话三表创建成功；使用一次性占位环境变量执行 `docker compose config --quiet` 通过。
- 视觉回归：在真实本地服务上逐页访问，桌面使用 1280 x 720，移动使用 390 x 844；模型与评测数据集详情及既有关键流程均无页面级横向溢出，详情数据在移动端转为单列阅读。
- 数据真实性：Redis、Milvus、Neo4j、Ollama、MCP 和数据库均使用实时探针；租户、审计、文档、模型和评测不使用随机数或静态演示记录。

## 当前边界

- 项目尚无平台级租户目录、计费系统和跨租户配额执行器，因此管理端只展示当前令牌租户；创建租户和调整配额保持禁用。
- 租户运行详情中的审计分布最多覆盖最近 200 条事件；服务探针详情没有时序历史，不能用于声称 SLA 或长期可用率。
- 项目尚无 SCIM 目录同步，因此企业成员页只展示 JWT 当前身份和审计窗口内已观测身份；邀请成员保持禁用。
- 企业活动页只查询当前 JWT 租户，不能用于平台级跨租户调查；接口要求 `audit:read`，无权限身份会明确收到拒绝响应。
- 文档任务页是只读追踪面：用户端仅可见 owner/ACL 授权文档，企业端可见当前租户；取消、强制重试、死信恢复和 Worker 租约检测尚未接入，历史遗留的执行中任务必须由运维核查 Worker 与队列状态。
- Worker 队列页读取即时 Redis 和数据库状态，但没有独立心跳、租约超时判定与时序历史；消费者注册和 idle 不能用于承诺在线率或 SLA。
- 知识索引页执行即时只读查询：Milvus 文档扫描上限为 10,000 条索引记录，页面最多返回 100 份文档检查；超限时文档级结论明确标记未知。该页不替代 Recall、MRR 等检索质量评测，也不执行自动修复。
- MCP 连接详情只探测服务端发布目录中的预配置 URL，前端不能指定目标；页面与 HTTP 客户端 INFO 日志均不返回路径、凭据或查询参数，也没有时序可用率、告警确认、凭据轮换和在线变更能力。
- 已观测成员详情不会推断非当前身份的角色、组或权限；接入企业 IdP/SCIM 前不能把该页面当作完整成员目录。
- Ollama `/api/ps` 提供当前加载模型的显存占用，但不提供 GPU 总量/利用率、QPS 和请求队列；模型页只展示可核验快照，不推测并发容量或长期趋势。
- 评测原始数据缓存位于被忽略的 `evals/data/`，不随仓库和容器分发；版本库保存来源、抽样口径、期望摘要、评测脚本、指标与报告，本地下载后才能重新执行完整实验。
- 维护操作需要审批、后台任务、结果审计和回滚链路，当前保持禁用，不能直接宣称满足大规模生产控制面要求。
- 会话正文现已持久化到业务数据库；生产部署必须配置数据库静态加密、备份访问控制、法务确认的保留期和按用户请求删除流程。
- 检索证据默认只在 Redis 保存 15 分钟并绑定租户与用户；原文件预览与下载已实现，但 PDF 页码/坐标高亮仍需检索元数据和解析器提供定位信息。
- 本次本地检索回归识别到 Ollama 未运行，接口将明确的连接或超时故障映射为可观测 503 并写入脱敏失败审计；证据详情通过真实上传文档和项目缓存函数验证。
- 当前浏览器验收覆盖主要桌面与移动视口；正式上线前仍需补充多浏览器、键盘全流程、屏幕阅读器和高并发压测。
