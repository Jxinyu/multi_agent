# 设计系统

## 设计主张

视觉主题为“工业印刷与信号系统”。界面使用清晰的网格、硬朗分隔线、编号标签和高辨识度状态色，避免常见 AI 产品的紫蓝渐变、发光球体、玻璃拟态和大面积深蓝背景。

用户端允许更强的视觉节奏和动态反馈；企业端与管理端保持高信息密度、低干扰和强扫描性。

## 颜色

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 雾白 | `#F2F4F1` | 页面背景 |
| 纯白 | `#FFFFFF` | 工作区、表格和弹层 |
| 碳黑 | `#171A18` | 主文字、主导航和强边框 |
| 石墨灰 | `#5D625E` | 次级文字 |
| 线框灰 | `#D6DAD5` | 分隔线和输入框 |
| 朱红 | `#F04424` | 主操作、关键提醒和活动状态 |
| 硫黄绿 | `#D9F03A` | 成功状态、运行状态和重点数字 |
| 钴蓝 | `#2855D9` | 链接、证据定位和数据系列 |
| 青绿 | `#00A69C` | 图表辅助系列和健康状态 |
| 洋红 | `#D6408F` | 图表辅助系列和异常对比 |
| 警示黄 | `#F6C744` | 等待、降级和人工处理 |

禁止使用渐变作为页面、卡片或按钮背景。图表至少使用三种语义明确的系列色，不能用同一色相的深浅变化填满页面。

## 字体与层级

- 中文字体：`Inter, "Noto Sans SC", "Microsoft YaHei", sans-serif`。
- 数据和标识符：`"IBM Plex Mono", "Cascadia Code", monospace`。
- 页面标题：28px/36px，700，仅用于一级页面。
- 面板标题：16px/24px，650。
- 正文：14px/22px，400。
- 辅助信息：12px/18px，500。
- 字间距固定为 `0`，不使用负字距或随视口缩放字号。

## 网格与形态

- 桌面设计基准：1440 x 1024。
- 用户端移动基准：390 x 844。
- 桌面左导航：216px；顶部栏：56px；内容安全边距：24px。
- 企业端和管理端内容采用 12 列网格，列间距 16px。
- 圆角上限 8px；表格、工具栏和页面分区优先使用分隔线，不把每个区域都做成悬浮卡片。
- 图标统一使用 Lucide，常见操作使用图标按钮并提供悬停提示。
- 阴影只用于弹层、浮动输入框和拖拽对象，普通内容不使用装饰性阴影。

## 三端差异

### 用户端

- 对话和证据是第一视觉焦点，减少固定表格。
- 使用朱红表示当前智能体，硫黄绿表示任务完成，钴蓝表示可核验证据。
- 可以使用过程轨迹、状态脉冲、内容展开和页面切换动画。

### 企业端

- 面向重复操作，优先表格、筛选器、批量操作和可恢复任务状态。
- 主操作只在页面右上角出现一次，避免多个同权重按钮。
- 配置变更必须显示草稿、已发布、失败和回滚状态。

### 管理端

- 面向平台风险和资源治理，强调租户范围、审计主体、时间和影响范围。
- 危险操作使用朱红描边，不使用大面积红色背景。
- 系统健康必须区分正常、降级、故障和未知，未知不能自动视为正常。

## 响应式原则

- 用户端完整支持 390px 宽移动设备。
- 企业端和管理端在窄屏下折叠导航，表格保留关键列并提供行详情抽屉。
- 固定工具栏、输入框、筛选器和状态条必须有稳定尺寸，动态内容不能造成布局跳动。
- 所有文本必须在容器内换行或截断，不能与按钮、图标和相邻内容重叠。
